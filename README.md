# ZEMPRO

Site de ZEMPRO : inscription des conducteurs de taxi-moto, abonnement, paiement Mobile Money et communautés de stations.

Voir `CLAUDE.md` pour le périmètre, la stack et le plan de construction.

```
npm install
cp .env.example .env.local   # puis remplir les valeurs
npm run dev                  # http://localhost:3000
npm run lint
npm run test
npm run build
```
